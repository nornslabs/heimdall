# migrations

Alembic migrations for every module's tables. `env.py` imports each `modules/*/models.py`
through `heimdall.adapters.db.metadata.import_all_models()`, so autogenerate sees all tables.

```bash
export HEIMDALL_DATABASE_URL=postgresql://heimdall:heimdall@localhost:5432/heimdall
uv run alembic upgrade head
uv run alembic revision --autogenerate -m "<module>: <change>"
```

Review every autogenerated file before committing; autogenerate misses some changes.
